# PlantAI

A mobile-first Next.js MVP for camera-based plant identification, visible-health guidance, and contextual care chat.

## Run locally

1. Copy `.env.example` to `.env.local` and add a Groq API key (optional for demo mode).
2. Run `npm install`.
3. Run `npm run dev`.

Without `API_KEY`, every scan returns structured demo data and visibly identifies itself as Demo Mode.
